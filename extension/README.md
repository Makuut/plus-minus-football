# Plus Minus Football Extension

## Установка

1. Откройте `chrome://extensions/` или `edge://extensions/`.
2. Включите режим разработчика.
3. Нажмите `Load unpacked` / `Загрузить распакованное расширение`.
4. Выберите папку `extension`.

После установки нажмите на иконку расширения. Анализатор откроется в новой вкладке.

Данные сохраняются в `localStorage` внутри расширения. Если нужно перенести данные из старой HTML-версии, сначала сделайте там `экспорт`, затем в расширении нажмите `импорт`.
