# ⚽ Football TTD Analyzer

Интерактивный инструмент для сбора и анализа технико-тактических действий (ТТД) футболистов во время матча.

## 🎯 Что это?

Приложение позволяет тренерам, аналитикам и болельщикам вести подробную статистику игры с разбивкой по временным периодам. Каждое действие отмечается знаком `+` (успешное) или `−` (неуспешное), что позволяет оценить эффективность игроков и команд в реальном времени.

## ✨ Возможности

- **👥 Управление игроками** — добавление/удаление, распределение по командам, цветовая маркировка
- **⏱️ Периоды матча** — гибкая настройка временных отрезков для детального анализа
- **📊 Показатели** — создание любых категорий (удары, перехваты, передачи, обводки и т.д.)
- **➕/➖ Учёт действий** — мгновенное добавление положительных и отрицательных действий одним кликом
- **📈 Визуализация** — автоматический расчёт процента успешности, подсветка строк и столбцов
- **💾 Автосохранение** — все данные хранятся в браузере и не теряются после перезагрузки
- **📤 Экспорт в CSV** — копирование статистики в буфер обмена для отчётов и дальнейшего анализа

## 🛠️ Технологии

- Чистый HTML / CSS / JavaScript
- Без внешних зависимостей
- Адаптивный дизайн
- Хранение в localStorage

## 🚀 Как запустить

1. Скачайте файл `football-analyze.html`
2. Откройте его в любом браузере
3. Начинайте заполнять статистику!

## 📋 Пример использования

1. Добавьте игроков и команды
2. Создайте нужные показатели (УДАРЫ, ПЕРЕХВАТЫ, ПАСЫ)
3. Разбейте матч на периоды (1-15', 16-30', 31-45')
4. Отмечайте действия в реальном времени
5. Анализируйте статистику и экспортируйте в CSV

## 📁 Формат экспорта

CSV-файл содержит статистику по каждому периоду и итоговую сводку "ВСЕГО" в формате:
Период;Команда;Игрок;УДАРЫ;ПЕРЕХВАТЫ;ПАСЫ;Итого
