# Plus Minus Football

Инструмент для фиксации и анализа технико-тактических действий (ТТД) футболистов по командам и периодам матча. Каждое действие записывается как успешное (`+`) или неуспешное (`−`), а приложение автоматически считает количество действий и процент успешности.

Проект доступен в двух вариантах:

- `football-analyze.html` — автономная версия в одном HTML-файле;
- `extension/` — расширение Manifest V3 для Chrome и Edge, позволяющее заносить действия горячими клавишами прямо на вкладке с видео.

## Возможности

- добавление и удаление игроков, показателей и периодов, распределение игроков по командам;
- отдельная статистика по каждому периоду и активному периоду матча;
- фиксация `+` и `−` кнопками или последовательностью горячих клавиш;
- удаление последнего `+`, последнего `−` либо всех действий в выбранной ячейке;
- автоматический подсчёт действий и успешности игроков, команд и показателей;
- цветовая маркировка игроков и подсветка строк и столбцов таблицы;
- автосохранение состояния;
- настройка начальных команд, игроков, показателей и клавиш действий;
- экспорт и объединяющий импорт исходных данных в JSON;
- скачивание итогового отчёта в CSV с разбивкой по периодам и блоком `ВСЕГО`.

## Быстрый запуск автономной версии

1. Скачайте или клонируйте репозиторий.
2. Откройте `football-analyze.html` в современном браузере.
3. Добавьте игроков, выберите команды и при необходимости настройте показатели и периоды.

Сервер, сборка и установка зависимостей не требуются. Данные и настройки автономной версии сохраняются в `localStorage` браузера для страницы, из которой открыт файл.

## Установка расширения

1. Откройте `chrome://extensions/` в Chrome или `edge://extensions/` в Edge.
2. Включите режим разработчика.
3. Нажмите «Загрузить распакованное расширение» (`Load unpacked`).
4. Выберите папку `extension`.
5. Нажмите значок расширения и выберите «Открыть таблицу ТТД».

Расширение хранит таблицу и настройки в `chrome.storage.local`. Эти данные доступны странице анализатора, фоновому обработчику и вкладкам с видео, но не совпадают с хранилищем автономного HTML-файла.

## Работа с таблицей

При первом запуске создаются показатели `ПАС`, `УДАР`, `ПЕРЕХВАТ`, `ОТБОР`, `ОБВОДКА` и период `1-10`. Команды, игроки и сочетания по умолчанию можно изменить через кнопку «настройки».

Обычный сценарий:

1. Укажите команду, имя и одноклавишное сокращение игрока, затем нажмите «+ игрок».
2. Добавьте или удалите показатели.
3. Создайте периоды и выберите активный период.
4. Заносите действия кнопками `+` и `−` в таблице либо горячими клавишами.
5. В меню `•••` ячейки при необходимости удалите последнее действие или очистите ячейку.
6. Скачайте резервную копию через «экспорт» или готовый CSV через «отчёт».

Сброс удаляет игроков и статистику и заново создаёт структуру из текущих настроек по умолчанию.

## Горячие клавиши

Действие вводится последовательностью из трёх клавиш:

```text
игрок → показатель → действие
```

Например, при стандартных настройках `1`, `q`, `+` добавляет успешный пас игроку с клавишей `1` в активном периоде.

Стандартные клавиши действий:

| Операция | Клавиша |
| --- | --- |
| Добавить успешное действие | `+` |
| Добавить неуспешное действие | `-` |
| Удалить последний `+` | `/` |
| Удалить последний `-` | `*` |

Клавиши игроков, показателей и действий настраиваются в интерфейсе. Сочетания должны быть уникальны внутри своей группы.

В автономной версии последовательность вводится на странице анализатора и сбрасывается через 1,5 секунды бездействия. В расширении:

1. Настройте таблицу и активный период.
2. Откройте меню расширения и нажмите «Активировать».
3. Перейдите на страницу с видео и вводите те же последовательности клавиш.
4. По окончании нажмите «Отключить».

Расширение показывает состояние `ON`/`OFF` на значке и краткое уведомление поверх страницы. Буфер ввода сбрасывается через 2,5 секунды или по `Escape`. Повторное удержание клавиши и ввод в `input`, `textarea`, `select`, редактируемых элементах и полях с ролью `textbox` не перехватываются.

Расширение подключает обработчик ко всем URL и фреймам (`<all_urls>`), поэтому включайте режим записи только на время работы с матчем. На системных страницах браузера расширения обычно не выполняются из-за ограничений самого браузера.

## Импорт и экспорт

Кнопки внизу таблицы выполняют разные задачи:

- «экспорт» скачивает `source.json` — полную резервную копию игроков, периодов, показателей и действий;
- «импорт» принимает один или несколько JSON-файлов и добавляет их содержимое к текущим данным;
- «отчёт» скачивает `report.csv` в кодировке UTF-8 с BOM и разделителем `;`.

При импорте игроки совпадают по точной паре «имя + команда», а показатели и периоды — по названию. Совпавшие записи объединяются, действия дописываются к существующим; импорт не заменяет текущую таблицу. Для переноса между автономной версией и расширением экспортируйте `source.json` в одной версии и импортируйте его в другой.

CSV содержит отдельный раздел для каждого периода и итоговый раздел `ВСЕГО`. В каждом разделе есть строки игроков, у которых были действия, и строки `Итого` по командам. Формат колонок:

```text
Период;Команда;Игрок;<показатели...>;Итого
```

Значение показателя записывается как `количество (процент успешности)`, например `12 (75%)`.

## Технологии и ограничения

- чистые HTML, CSS и JavaScript без сторонних зависимостей и этапа сборки;
- браузерное расширение использует Manifest V3 и разрешения `storage`, `tabs`, а также доступ к `<all_urls>` для горячих клавиш;
- данные остаются локально в профиле браузера, пока пользователь не экспортирует файл;
- очистка данных сайта, удаление расширения или удаление его хранилища может стереть несохранённую статистику — регулярно сохраняйте `source.json`.
