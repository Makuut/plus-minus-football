# Plus Minus Football Extension

## Установка

1. Откройте `chrome://extensions/` или `edge://extensions/`.
2. Включите режим разработчика.
3. Нажмите `Load unpacked` / `Загрузить распакованное расширение`.
4. Выберите папку `extension`.

После установки нажмите на иконку расширения. Анализатор откроется в новой вкладке.

## Работа с видео

1. Откройте анализатор через иконку расширения и настройте игроков, показатели, период и горячие клавиши.
2. Откройте вкладку с видео.
3. Нажимайте горячие клавиши прямо на вкладке с видео: `игрок` -> `показатель` -> `действие`.
4. Если вкладка анализатора открыта, таблица обновится автоматически.

Расширение слушает клавиши только на страницах, где есть HTML5-видео. Ввод в полях, textarea и select не перехватывается.

Данные сохраняются в `chrome.storage.local`, общем для страницы анализатора и вкладок с видео. Если нужно перенести данные из старой HTML-версии, сначала сделайте там `экспорт`, затем в расширении нажмите `импорт`.
