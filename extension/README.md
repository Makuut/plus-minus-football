# Plus Minus Football Extension

## Установка

1. Откройте `chrome://extensions/` или `edge://extensions/`.
2. Включите режим разработчика.
3. Нажмите `Load unpacked` / `Загрузить распакованное расширение`.
4. Выберите папку `extension`.

После установки нажмите на иконку расширения. Анализатор откроется в новой вкладке.

## Работа с видео

1. Нажмите на иконку расширения, откройте таблицу ТТД и настройте игроков, показатели, период и горячие клавиши.
2. Снова нажмите на иконку расширения и нажмите `Активировать`.
3. Откройте вкладку с видео.
4. Нажимайте горячие клавиши прямо на вкладке с видео: `игрок` -> `показатель` -> `действие`.
5. После работы откройте меню расширения и нажмите `Отключить`. Если таблица ТТД открыта, она обновится автоматически.

По умолчанию горячие клавиши неактивны. После явной активации они работают на любой веб-странице. Ввод в полях, textarea, select и других редактируемых элементах не перехватывается.

Данные сохраняются в `chrome.storage.local`, общем для таблицы ТТД и вкладок с видео. Если нужно перенести данные из старой HTML-версии, сначала сделайте там `экспорт`, затем в расширении нажмите `импорт`.
